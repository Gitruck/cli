# 成片型图纸公约（正本）

> **射程**：一切分场景横切的剪辑/成片 structure 级图纸（旅拍、口播链、直播切片、Vlog 纪实……）。
> **性质**：写图纸时的公约与自检清单，**非运行时加载**——图纸必须自包含，本文是正本、图纸内是执行文本；
> 改公约 MUST 同批同步全部执行文本（登记表见 §五）。本文不进 npm 分发白名单（写作时约束，非客户交付物）。
> **立法**：主理人 2026-08-27 拍板（看板①「懒人模式」新定调，change add-production-skill-charter）。

## 一、双模式公约

每张图纸 MUST 提供两种模式，命名统一：

- **快速成片**（弃名「懒人模式」「快速模式」——前者难听且误导定位，后者只说了快没说成什么）：
  开工问询一次拍板 → 极少数结构化必停 → 一杆到底。
- **逐步推进**（旅拍语境亦称「精修」，可作别名并列）：每步停等确认。

两模式共用同一套规约与参数配方，**差别只在停几次，不在停不停**。

快速成片 ≠ 甩手掌柜。它不是让用户少参与，而是**参与时机全部前移**——低门槛带来的
「货不对板」失望感，根源都是某个本该用户拍的板被 agent 代拍了；把板前移，
跑完就没有可失望的悬念。一句话：**丑话说在前面，底层决策前置。**

## 二、决策前置三条腿

写图纸时逐个盘「agent 会替用户拍什么板」，每个点 MUST 归入三条腿之一，不许悬空：

1. **能前置的决策 → 开工问询一次拍板。**
   实例：口播链五问（多条形态 / 外录 / 文稿 / 几何 / B-roll 来源）、直播切片四问
   （时长几何 / 画面形态 / 贴片 / MG）、旅拍双场景识别。
   问询 MUST NOT 代猜（猜错代价大的点尤其如此），也 MUST NOT 碎问——一张表一次答完。
2. **开跑前不存在的决策 → 结构化必停。**
   停一次、清单式一次决策、不碎问。实例：直播切片选题清单（选题决策在跑之前不存在，
   前置不了）；旅拍/口播链检查点①（写完稿 / 粗剪完才有对象可拍板——稿件、画幅、音色、
   BGM、字幕样式一屏给齐）。**计费动作恒在停点之后**：未经确认 MUST NOT 发起计费。
3. **前置不了也停不住的（概率性 / 平台边界）→ 丑话说在前面 + 缺省不硬塞。**
   实例：直播切片贴片如实告知（告知不处置）、计费与实时价格转述、B-roll/MG 等可选增强
   缺省不铺不硬塞（问了/要了才做）、对轨低置信才请人工、字幕样式没选就 default 不追问、
   交付物边界先说清（粗剪工程 ≠ 成片）。

## 三、MG 风格：内容驱动的临场泛化（正本，自口播链图纸 §六 迁此）

射程 = 所有含 MG 铺轨面的成片型图纸：

- **有栏目风格 skill** → 走栏目（经栏目配置注入），本节不适用。
- **没有** → 按**当下这片的内容**现场泛化一套自洽风格直接用：
  1. 内容调性 → 风格基调：讲什么（严肃知识 / 情感陪伴 / 轻快种草）→ 配色倾向、字体气质、
     动效克制度（知识类稳、情绪类柔、种草类快）；
  2. 基调定了**全片贯彻**：同片所有颗粒同一套色板与字体气质，MUST NOT 逐颗粒各自为政；
  3. **两个 MUST NOT**：不把某套固定「通用默认风格」死板套所有片子（换了形态的强行锚定）；
     不因无栏目 skill 放弃风格一致性（那是没有风格）。
- 一句话：**风格必须有，但不强行锚定**——锚在这一片的内容上，而非某个预设模板上。

（spec 条款住 talking-head-skill capability「MG 风格采用内容驱动的临场泛化」；旅拍 §六
「因势象形」是其垂类实例。）

## 四、写图纸自检清单（新图纸 / 改图纸时逐项过）

- [ ] 双模式在场且命名 = 快速成片 / 逐步推进；差别只在停几次
- [ ] 逐个盘「agent 会替用户拍什么板」，全部归入三条腿之一，无悬空
- [ ] 结构化停点：清单式一次决策，不碎问；计费动作在停点之后
- [ ] 缺省不硬塞：可选增强（B-roll / MG / BGM / 分屏……）缺省不做，问了才做；答「不要」= 零动作不再追问
- [ ] 丑话在前：概率性质量、平台边界、计费、交付物边界，开跑前说清
- [ ] 含 MG 面的图纸带临场泛化执行文本（§三）
- [ ] 文风铁律照继承（正本在 gtrk-travel-recap §三通用框架层，与本公约并行、不互替）
