# 封面交付自检清单（两阶段 · 9 条硬规）

交付前**一条一条对着过**，不合格直接说不合格，不要糊弄。
按交付阶段分两组：阶段一在**交付 Prompt 时**核，阶段二在**交付排版工作台时**补核。

---

## 阶段一：交付 Prompt 时核（①~⑤）

### ☐ 1. 意象与视频核心概念一致
封面上的意象是不是**这个视频真正讲的东西**？
- 意象必须来自视频内容本身的视觉化，不能是随便一张好看的"情绪贴纸"。
- 栏目如有自己的「概念 → 意象」对照体系，从其封面风格资产读取并按其对照检验。
- **不合格的典型**：核心概念和画面互不相干，画面只负责好看。

### ☐ 2. 情绪与视觉对齐
当期情绪基调和**色板 + 表情 + 构图**是否对齐？
- 栏目风格资产如定义了情绪轴 / 情绪-色板绑定，按其轴判；未定义则按常识判。
- 常识底线：绝望段不要画笑脸；克制段不要画嚎叫；悬念钩子要有"正在降临"的不祥感而不是已经发生的惨状。

### ☐ 3. 封面与标题的互文
封面大字（T1）和视频标题是否**组成完整钩子**？
- 通过检验：只看标题不看封面，信息不完整；只看封面不看标题，也不完整；两者合起来才完整。
- 不通过：封面上直接把标题原样写了一遍（重复冗余）；或者封面字和标题完全无关（脱节）。
- T1 通常是用户自己拟的 4~10 字核心句，**本 skill 不擅自改写 T1 内容**，只能建议字体 / 拆分 / 重音处理。

### ☐ 4. 材质层已写进 Prompt
Prompt 里是否至少叠加了 1 层胶片颗粒 / 纸张纹理 / 印刷网点？
- 没有材质层 = AI 直出光滑感，与目标质感有明显差距。

### ☐ 5. 生成图低级错误提示
是否向用户显式提示了生成图的常见低级错误，提醒挑图时逐项检查？
- 多出来的手指 / 眼睛 / 发丝等解剖错误。
- 中文字符乱码。
- 手部特写、多人交叠等高危题材要**显式提醒**用户多生成几张挑图。

---

## 阶段二：交付排版工作台时补核（⑥~⑨）

### ☐ 6. 字的主视觉重量
T1 在画面里是否具有**主视觉重量**，手机缩略图上能读清？
- 4 字 T1：单字高度 ≥ 画面高 15%（整体 T1 区 ≥ 35%）。
- 6~8 字 T1（含对偶）：每半句字号保证手机缩略图上能读清。
- 长句 T1 必须用"关键词重音法"——关键词字号明显大于副行，否则整句堆成同样大会糊。
- 铁律：最大化利用可用区域。

### ☐ 7. 留字位落点
默认文字坐标是否落在画面的**气口**（干净留白区）？
- 主体没把所有关键区域吃满；文字区背景干净、无高频细节干扰。
- 栏目风格资产如有留白 / 密度规范，按其规范判。

### ☐ 8. 身份锚不编造
- 用户给了栏目名 → 品牌戳是否合理放置（没压主视觉，没挤出安全区）？
- 用户没给 → 是否没瞎编，排版稿里老实标注"未提供，可省略"？
- 期号同上逻辑。

### ☐ 9. 分发平台安全区
按用户的分发平台适配安全区，关键元素（T1 / 主体五官 / 身份锚）不进裁切与遮挡区。
- B 站参考值：右上 1/8 角标区、底部 1/10 进度条灰化区。
- 其他平台按各自的裁切 / 遮挡规则判，不作无条件硬规。
- 主体脸不被 T1 大字压到"看不出表情"（可以压边缘，不可以压到五官中心）。

---

## 输出时的写法

```
自检结果（阶段一）：
  1. 意象与核心概念 ✅ — 核心概念的视觉化贯穿主体
  2. 情绪与视觉对齐 ✅ — 冷峻诊断段，冷色板吻合（依栏目风格资产）
  3. 封面-标题互文 ⚠️ — T1 与标题组成钩子，但建议 T1 拆为单字重音，让标题承担更多
  4. 材质层 ✅ — Prompt 已含胶片颗粒
  5. 低级错误提示 ⚠️ — 含手部特写，已提醒多张挑图并检查手指

自检结果（阶段二）：
  6. 字够大 ✅
  7. 留字位落点 ✅
  8. 身份锚 ❓ — 尚未提供栏目名，已标注"未提供，可省略"
  9. 平台安全区 ✅ — 按 B 站规则避开右上角标区与底部进度条区
```
