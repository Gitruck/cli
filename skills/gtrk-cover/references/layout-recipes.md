# 布局配方（Layout Recipes）

8 种布局（L1 / L1-对偶 / L2 / L2-长句 / L3 / L4 / L5 / L6），**每种都给出 16:9 / 4:3 / 3:4 三个尺寸的区域分配**。

术语约定：
- **T1** = 主视觉大字（用户亲拟，典型 4~10 字，字数决定布局路由）
- **T2** = 副标题条（≤12 字钩子短句）
- **T3** = 角标信息（Vol.X / 期号 / 系列名）
- **T4** = 品牌戳
- **T5** = 装饰英文
- **S** = 主体（Subject，角色或意象）

> 铁律：本文件只持有工艺骨架（几何 / 字数路由 / 槽位结构）。凡色板、字体、参考封面等审美取值，一律由**栏目封面风格资产**供给，框架零预设。

---

## L1 「左右分飞」—— 仅适用 4 字 T1

**一个字在画面左，一个字在画面右（4 字则左右各 2 字），中间给主体。T1 的字**大到占画面高度的 60~80%**，部分被主体压在身后。

**适用**：**严格只用于 4 字 T1**。单人物 / 单意象、强对称感、最核心向选题。  
**不适用**：5 字以上，或含逗号对偶句——那些用 L1-对偶变体 / L2 / L2-长句变体。  
**参考气质**：单一意象顶天立地、文字与主体互相穿插的对称海报感。

```
┌────────────────────────┐
│ T3                     │  ← T3 角标贴边缘对角分布
│                        │
│ [T1左]   [  S  ]  [T1右]│  ← T1 字压在 S 肩线以上/以下
│                        │
│ T2              T4     │
└────────────────────────┘
```

**16:9（2400×1350）**：
- T1 左：x=0~500, y=250~1050，字高约 800px
- S（主体）：x=700~1700，垂直居中
- T1 右：x=1900~2400, y=250~1050
- T2：x=60~900, y=1180~1280（左下副标题）
- T3：x=60~700, y=60~160（左上角标）+ x=1700~2340 右上镜像
- T4：x=60~500, y=1280~1330（品牌戳叠在 T2 下方）

**4:3（2400×1800）**：按同上比例，但 S 区域更宽更饱满，T1 竖向拉长。

**3:4（1500×2000）**：左右分飞变成**上下分飞**——T1 的一个字在画面顶部，另一个在底部，主体在中段。

#### L1 — H5 工作台默认坐标（直接抄进 DEFAULTS）

```js
const DEFAULTS = {
  // 16:9 左右分飞（横板 L1 经典）
  '16_9': {
    canvas: { w: 2400, h: 1350 },
    layers: {
      char1: { type: 't1', pos: '左上', left: 140,  top: 200,  size: 520 },
      char2: { type: 't1', pos: '左下', left: 260,  top: 720,  size: 520 },
      char3: { type: 't1', pos: '右上', left: 1740, top: 200,  size: 520 },
      char4: { type: 't1', pos: '右下', left: 1620, top: 720,  size: 520 },
      t2:    { type: 't2', pos: '底部居中', text: '{T2 副标}',    left: 910,  top: 1200, size: 46, visible: true },
      t5:    { type: 't5', pos: '顶部居中', text: '{T5 装饰英文}', left: 1020, top: 80,   size: 34, visible: true },
    },
  },
  // 4:3 对角分飞（横版饱满，适合主体顶到三边的背景）
  '4_3': {
    canvas: { w: 2400, h: 1800 },
    layers: {
      char1: { type: 't1', pos: '左上', left: 110,  top: 150,  size: 560 },
      char2: { type: 't1', pos: '左中', left: 300,  top: 700,  size: 560 },
      char3: { type: 't1', pos: '右中', left: 1540, top: 540,  size: 560 },
      char4: { type: 't1', pos: '右下', left: 1730, top: 1090, size: 560 },
      t2:    { type: 't2', pos: '右下角', text: '{T2 副标}',    left: 1680, top: 1680, size: 44, visible: true },
      t5:    { type: 't5', pos: '左上角', text: '{T5 装饰英文}', left: 130,  top: 75,   size: 36, visible: true },
    },
  },
  // 3:4 上下分飞（竖版 L1，顶部 2 字 + 底部 2 字，主体夹中段）
  '3_4': {
    canvas: { w: 1500, h: 2000 },
    layers: {
      char1: { type: 't1', pos: '左上', left: 180, top: 140,  size: 440 },
      char2: { type: 't1', pos: '右上', left: 880, top: 140,  size: 440 },
      char3: { type: 't1', pos: '左下', left: 180, top: 1380, size: 440 },
      char4: { type: 't1', pos: '右下', left: 880, top: 1380, size: 440 },
      t2:    { type: 't2', pos: '中段留白', text: '{T2 副标}',    left: 475, top: 620,  size: 44, visible: true },
      t5:    { type: 't5', pos: '底部居中', text: '{T5 装饰英文}', left: 550, top: 1880, size: 34, visible: true },
    },
  },
};
```

**说明**：
- 工作台模板已按 T1_KEYS 常量字数驱动，图层数随 T1 字数实例化（5 字即 char1~char5），不再写死 4 字。
- `char1-charN` 的 `text` 字段会被运行时的 T1 输入框同步覆盖，DEFAULTS 里不用写。
- `size` 是默认字号，用户可以在工作台里逐字调。字号单位是像素（画布坐标）。
- `pos` 是右栏 block 上显示的位置标签，**不影响**实际坐标。
- T2 的 `left` 值是视觉上居中的估算，不会精确——用户可以拖。

## L1-对偶 「对偶分飞」—— 适用 6~8 字含逗号句

**对偶句（6~8 字、中间一个逗号）专用**：上半句和下半句各占一半画面区域，对称铺开。典型如「圣人不死，大盗不止」「先有能量，后有爱」。

**两种子形式**：
- **左右对偶**：上半句靠左，下半句靠右（适合 16:9 / 4:3 横板）
- **上下对偶**：上半句在画面上 1/3，下半句在画面下 1/3，主体在中间（适合 3:4 竖板，也可用于横板）

```
左右对偶（横板推荐）：          上下对偶（竖板推荐）：
┌─────────────────┐          ┌───────────┐
│ 上半句          │          │ 上半句     │
│    ┌─────┐     │          │           │
│    │  S  │     │          │    S       │
│    └─────┘     │          │           │
│          下半句 │          │     下半句 │
└─────────────────┘          └───────────┘
```

**重要技巧**：对偶两半的**对应位置关键字**可以**同字号或略大**，作为视觉重音。
- 例：「圣人·大盗」分别成为两半的重音，"不死·不止"略小。

## L2 「左人右字」—— 最高频、最通用

**主体占画面左半，大字竖向或横向堆在右侧**。经典版式，信息密度高。

**适用**：有明确人物 / 意象 + 需要清晰阅读文字的选题。  
**参考气质**：人物立绘 / 主意象与竖排大字对望的经典杂志式排版。

```
┌────────────────────────┐
│                    T3  │
│              ┌──────┐  │
│      S       │ T1 字│  │
│              │ T1 字│  │
│              └──────┘  │
│              T2        │
│ T4                     │
└────────────────────────┘
```

**16:9**：S 占左 55%，T1 堆在右 40% 居中。  
**4:3**：S 占左 50%，T1 占右 45%。  
**3:4**：改为"上图下字"或"上字下图"——竖版把 L2 旋转 90°。

## L2-长句 「关键词重音」—— 适用 9+ 字长句

**专门处理长句 T1**（如「集体潜意识的创伤释放」「你要选择怎样的人生」）：抽出 2~4 个关键字做超大重音，其余字做中号副行。

```
┌───────────────────────────┐
│ T3                        │
│              ┌─────┐      │
│   副行1      │ 重   │     │
│   副行2      │ 音   │     │  ← "重音"2~4字 占画面高 40%
│     S        └─────┘      │  ← 副行字号是重音的 30~50%
│              T2           │
│ T4                        │
└───────────────────────────┘
```

**关键词选法**：从原句里挑**情绪/意象/动词最强**的 2~4 字作为重音。
- 「集体潜意识的创伤释放」→ 重音 **释放**，副行"集体潜意识的·创伤"
- 「你要选择怎样的人生」→ 重音 **选择** 或 **人生**，副行"你要·怎样的"

**重要**：副行字号小但**必须清晰**，不要做到手机上看不见。

## L3 「全景电影海报」

**主体做成全景式中心图，字压在底部或顶部横条**。最接近电影海报质感。

**适用**：史诗感 / 群像 / 全片概括向选题，尤其是主视觉本身有宏大场景（超新星、深海、废墟、城市）。  
**参考气质**：全景大场面压顶、底部字幕条收束的院线海报感。

```
┌────────────────────────┐
│ T3                 T5  │
│     [  大全景 S  ]     │
│                        │
│    ─────────────       │
│    T1    T1    T2      │
│ T4                     │
└────────────────────────┘
```

**16:9**：全景占上 70%，底部 30% 给字区。  
**4:3**：全景占上 65%，底部 35% 给字区。  
**3:4**：全景占上 75%，底部 25% 给字区。

---

## L4 「胶片 / 磁带 / 取景框」

**用画中画形式**：画面主体是一个"设备 / 媒介物"（取景器、磁带、老电视、海报），里面嵌套真正的内容图。

**适用**：元讨论 / 媒介批评 / 影评 / 访谈类选题。  
**参考气质**：媒介物做外框、内容图嵌套其中的画中画怀旧感。

```
┌────────────────────────┐
│ [设备外框装饰]          │
│   ┌─────────┐         │
│   │   内嵌   │  T1 T1 │
│   │    S    │  T2     │
│   └─────────┘         │
│ T3    设备细节   T4    │
└────────────────────────┘
```

**16:9**：内嵌图占中心 50%，设备外框占外围 50%。  
**4:3**：内嵌图占中心 55%。  
**3:4**：内嵌图占上 60%，下方 40% 留给 T1 大字和设备底部装饰。

## L5 「空灵素白 / 极简」

**大面积留白，主体以浅轮廓 / 线稿 / 透明叠加存在，T1 大字变成唯一视觉重量**。

**适用**：治愈 / 文学感 / 轻盈调性的选题。  
**参考气质**：大留白 + 淡彩线稿主体的文艺极简海报感。

```
┌────────────────────────┐
│ T3                     │
│                        │
│   T1 T1        ╱S╲    │  ← S 是半透明线稿/淡彩
│                  (浅)  │
│   T2                   │
│                  T4    │
└────────────────────────┘
```

色板：用栏目色板中**最浅 / 最柔**的一档（由栏目封面风格资产供给）。

---

## L6 「撕痕 / 色块拼贴」

**画面被几何色块或不规则撕痕切开**，主体在一块，字在另一块，制造"蒙太奇"感。

**适用**：有强反差 / 二元对立的选题（如"主人也是奴隶"、"爱与恨"、"狂喜与绝望"）。  
**参考气质**：色块切割、两半互撞的拼贴蒙太奇感。

```
┌────────────────────────┐
│ ╱ 色块A  ╲  ╱ 色块B ╲  │
│ │  T1    │  │  S    │  │
│ │  T2    │  │       │  │
│ │        │  │       │  │
│ ╲──────╱    ╲──────╱  │
│ T4              T3     │
└────────────────────────┘
```

色块 A / B 颜色需从栏目色板中选一对**对比色**（对比色对由栏目封面风格资产供给）。

## 选配表（快速决策）

### 第一步：按 T1 字数筛布局

| T1 字数 / 结构 | 主选布局 | 备选 |
|---|---|---|
| 4 字 | L1 左右分飞 | L3 全景底部整排 |
| 5 字 | L2 左人右字（右侧竖排） | L1（拆为 2+3 或 3+2） |
| 6~8 字含逗号（如"圣人不死，大盗不止"） | **L1-对偶** | L6 撕痕拼贴（每半句在一个色块里） |
| 6~8 字不含逗号 | L2 分两行 | L3 底部两行 |
| 9+ 字长句（如"集体潜意识的创伤释放"） | **L2-长句 关键词重音** | L5 极简（轻盈调性向） |

### 第二步：按选题气质选色板

方法条（框架只持有方法，不持有映射）：
1. 先定选题的**情绪 / 气质**（剖开、悬疑、史诗、温柔、对立、怀旧……）。
2. 再按「气质 → 色板」映射表选色板——该映射表由**栏目封面风格资产**持有，本 skill 运行时从风格资产读取注入。

### 第三步：品牌戳 / 期号放哪

**动态评估**，不固定：
1. 画出主视觉之后，看四角哪两个留白最多且**不在 B 站右上角标安全区**（右上 1/8）。
2. 品牌戳和期号分居两个角（避免扎堆）。
3. 用户**没给**就**不放**，留白的角保持留白（这反而更高级）。

## 其他布局的 H5 默认坐标（待补）

目前只有 **L1** 给出了完整的 H5 工作台 DEFAULTS JSON（见 L1 小节末尾）。

其他布局（L1-对偶 / L2 / L2-长句 / L3 / L4 / L5 / L6）**第一次用到时现场推算**，推算方法：

1. **T1 字符数** 决定 DEFAULTS 中 `layers` 里 T1 项的数量：
   - L1 / L1-对偶：4 个 `char1-char4`（对偶按 2+2 拆，即便句子是 6~8 字，也按"重音字"逻辑选 4 个最大字）
   - L2（5 字竖排）：5 个 `char1-char5`
   - L2-长句（关键词重音法）：2~4 个 `char1-charN` 做重音字 + 额外一个 `subline` 放副行长文本
   - L3（底部横排）：全部字在一行，按 T1 字数决定数量
2. **左/右边距**：横版一般 100~300px；竖版 150~200px
3. **字号**：按下表估算
   - 4 字 T1：400~600px（横版）/ 380~460px（竖版）
   - 5~6 字 T1：280~400px
   - 8 字对偶每字：240~320px
   - 长句关键词重音：400~600px；副行 120~200px
4. **T2 / T5**：每尺寸按画面气质选一个合理的位置（底部居中 / 右下 / 左上 等），字号参考 L1 的范围（T2 40~50，T5 30~40）

补完 JSON 后用同样的"推算说明"格式追加到对应布局小节末尾，以便下次复用。

## 生成 DEFAULTS JSON 的通用脚手架

不管什么布局，模板是：

```js
const DEFAULTS = {
  '16_9': {
    canvas: { w: 2400, h: 1350 },
    layers: {
      /* T1 各字：按布局拆分 */
      char1: { type: 't1', pos: '<位置标签>', left: <x>, top: <y>, size: <字号> },
      // ... 更多 char
      /* T2 副标 */
      t2:    { type: 't2', pos: '<位置标签>', text: '<默认副标>',    left: <x>, top: <y>, size: <字号>, visible: true },
      /* T5 装饰英文 */
      t5:    { type: 't5', pos: '<位置标签>', text: '<默认英文>',    left: <x>, top: <y>, size: <字号>, visible: true },
    },
  },
  '4_3': { canvas: { w: 2400, h: 1800 }, layers: { /* 同结构 */ } },
  '3_4': { canvas: { w: 1500, h: 2000 }, layers: { /* 同结构 */ } },
};
```

用户在工作台里能拖 / 调 / 改，所以 DEFAULTS 给的是"**不难看的起点**"而不是"最终版"。求稳不求精。
