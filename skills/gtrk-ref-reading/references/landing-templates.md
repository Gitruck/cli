# 精读目录落盘模板

> 骨架是起点，不是表单：章节随这条参考片长，没有的系统不硬写，多出来的就加。
> 时码一律写**源片秒**（如 `121.9`），需要时括注 `02:01.9`；证据路径写相对精读目录的路径。

```
<精读目录>/
├── ANALYSIS.md      整片模型
├── TIMELINE.md      时码细节
├── PROGRESS.md      接力
├── transcript.md    gtrk transcript 的可读稿
├── transcript.json  字级时码稿（gtrk media --transcript 吃它）
└── evidence/
    ├── overview/            整片概览网格（tiles 产物目录，含 index.json）
    ├── boundaries.json      视觉变化候选
    ├── <段落名>/            段落带台词网格
    ├── motion/<动效名>/      逐帧网格
    ├── <名>-frames/         大图（字体 / 配色）
    └── <名>.mp4             证据片段
```

---

## ANALYSIS.md

```md
# <栏目 / 参考片名> · 整片解读（ANALYSIS）

> 证据：<参考片路径>（<时长>，逐字转写 `transcript.json`）；交叉印证：<其它参考片>。时码细节见 `TIMELINE.md`，抽帧证据在 `evidence/`。
> 下文「看到的」是画面事实，「它在做什么」是解读。

## 一、这片想让观众得到什么
<观众看完能复述什么；它让人坐得住 / 看下去的办法是什么>

## 二、整片结构与节奏
| 段 | 时码 | 看到的 | 它在做什么 |
|---|---|---|---|
| 冷开场 | 0–6 | … | … |

切点密度：`boundaries` <参数> 测得 <N> 处视觉变化，平均约 <x>s 一变；<各系统单次停留时长>。

## 三、视觉 / 声音系统（每个系统写一次，状态变化见 TIMELINE）

### S1 <用这条片自己的样子命名>
- 看到的：<形态 / 位置 / 配色 / 字体气质>
- 状态：<出现 / 高亮 / 灰化 / 合并 / 换形态 / 退场……>
- 它在做什么：<对观众的作用>
- 首次出现：<秒>（`evidence/…`）
- 归属：<叠层 / 版式>——<讲者的位置、大小或可见区域变没变；依据哪张网格>

## 四、色彩与字体（从大图取的近似值）
- <角色>：<色值>，用在 <哪里>
- 字体气质：<标题 / 正文 / 数字 / 英文各是什么气质>

## 五、动效性格
- <如：快进慢驻——元素 4–6 帧到位，之后整幅慢推，见 `evidence/motion/…`>
- <如：状态变化多于出场；切走不清板>

## 六、迁移：哪些保留作用、哪些重做形式
| 系统 | 归属 | 目标上怎么落 |
|---|---|---|
| S1 … | 叠层 / 版式 | 保留：<作用>；重做：<目标上的形式>；不做：<什么及理由> |
```

## TIMELINE.md

每节一个「源片秒区间 · 段落意义」标题，节内写**对着哪句话、发生了什么、为观众做了什么、证据在哪**。
密集段落可以逐句列。同一个系统跨多节时，用 ANALYSIS 里的系统名指代它，只写这次的状态变化。

```md
# <参考片名> · 时码精读（TIMELINE）

> 源：<参考片>（<时长>）。时码 = 源片秒；字级时码见 `transcript.json`。

## 121.5–146.0 · 持续板：逐个排除（核心范例）
证据：`evidence/排除/`、`evidence/motion/stamp/`。
- 121.9「这个行业有 5 家大公司」→ S4 徽章板回来，左上小灰条标题，S2 讲者圆窗在左下。
- 123.9「第一家」→ 该徽章放大变亮；「买不动」→ S5 红色印章约 124.9s 落在徽章上（逐帧：4 帧到位、轻微过冲后回落）。
- 131.9「剩下的两家还可以」→ 两枚徽章变金黄（选中态）。
→ 观众每听到一个名字，眼睛就落到那枚徽章上；判断落章。插一句讲者全画面后板回来，状态保留。
```

## PROGRESS.md

```md
# 精读进度

- 目标：<学什么；套到谁的什么片上>
- 主读：<参考片>；交叉印证：<…>
- 当前问题：<正在弄清的一件事>
- 已读：<段落 / 系统清单>
- 未读：<段落 / 系统清单，带时码>
- 待查：<没看清的事 + 时码 + 打算用什么尺度看>
- 下一步：<一句话>
```
