# 精读清单（按系统类型）

> 清单是**提问的方向**，不是要填满的表：只问这条参考片里真实存在的系统。
> 每一问都要能落到 TIMELINE 的某一节（源片秒 + 对着哪句话 + 证据路径）。

## 动效（逐帧网格上看）

- **前一刻是什么、变了什么、之后留下什么。** 一个入场再漂亮，落定后的状态说不清论点也白搭——落定状态是重点。
- **几帧到位**：从第一帧可见到落定数帧号（网格标签带 `帧#n`），换算成秒；**到位之后**是静止、慢推、慢漂还是呼吸。
- **怎么动**：路径（直线 / 弧线 / 从哪个物件来）、缩放与透明度、有无过冲和回落、模糊或拖影。
- **和谁同步**：落在哪个字上（字头前已落定？字尾才到？）；和邻近事件谁先谁后；是否跟声音标点同拍。
- **物件身份**：同一个物件跨状态是否保持形状 / 颜色 / 轨迹（徽章变饼图、卡片变附件）；「淡出的副本」是不是它自己在退场。
- **硬切还是连续变化**：硬切适合「下一个想法一眼就懂」，连续变化适合「要看清怎么变的」。

## 构图与图形（大图上看）

- 眼睛**第一眼**落在哪、然后看哪；靠尺寸、间距、分组、对比、颜色还是运动建立层级。
- 讲者的位置给图形留了多大地方；讲者、图形、字幕谁在这一刻领衔。
- 配色：几种主色、各干什么（正向 / 负向 / 强调 / 底）；字体：标题 / 正文 / 数字 / 外文各是什么气质、字重、字距。
- 哪些是可编辑的结构（随话改变的数字、标签、状态），哪些只是素材（照片、截图、纹理）。

## 字幕与画面文字

- 字幕显示的是说出来的话；独立的标题、标签、意译属于排版 / 图形，不是字幕——分开记。
- 字幕的分组（一屏几字、按意群还是按句）、位置、强调方式、是否随讲者 / 画面让位。
- 每种**不同的配置**（讲者不同、位置不同、强调不同）各记一次，也记它们之间怎么切换。

## 讲者（A-roll）与画中画

- 讲者在画面里是什么角色：全屏聊天、缩成小窗继续在场、被图形临时替换。
- 观点句 / 吐槽句 / 转折句是否总回到讲者全画面，信息句交给图形——这是节奏语法，记清楚。

## 素材（B-roll）

- 素材在这一刻是**精确对应**（这句话必须看见这张图）还是**一组画面传达一个意思**（习惯、历史、过程、态度）。
- 素材被怎么处理：压暗做底、裁切、加框、局部高亮。

## 声音

- 音乐的起落是否标出段落；有没有声音标点（转场音、印章音、计数音）和画面同拍。
- 讲者声音在全屏素材下是否连续；换段时声音先走还是画面先走。

## 迁移时逐项问

- 这个系统在这里**干什么**？目标片里有没有同样的活要干？
- 目标换了人 / 产品 / 画幅 / 语言后，这个形式还成立吗？不成立就换一个能干同样活的形式。
- 删掉一个系统时，它原来干的活交给谁？
